# Kindo App

Aplicación móvil desarrollada en Flutter como parte de nuestro proyecto integrador llamado Kindo, correspondiente a la asignatura de Desarrollo de Aplicaciones Móviles.

## Que implementamos
- Interfaz desarrollada con Flutter y Dart.
- Almacenamiento local mediante SQLite.
- Consulta de servicios y prestadores.
- Visualización del perfil del cliente.
- Consulta de actividades.
- Navegación entre pantallas.

## Tecnologías utilizadas

- Flutter
- Dart
- SQLite

## Estructura del proyecto

- `lib/modelo/`: modelos y gestión de la base de datos.
- `lib/vista/`: pantallas y componentes de la interfaz.
- `assets/`: recursos gráficos de la aplicación.
- `lib/main.dart`: punto de entrada de la aplicación.
